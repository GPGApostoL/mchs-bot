# ЛЧС — Telegram Mini App

Темное Telegram Mini App для квалификационного тестирования. База вопросов загружается из DOCX, а Python-сервис одновременно запускает Telegram-бота и HTTP API.

## Что уже сделано

- 311 записей из исходного DOCX подключены к тесту.
- На один тест выбирается 50 случайных вопросов.
- Для каждого вопроса формируются 4 варианта ответа.
- Правильный ответ не отправляется клиенту до проверки.
- Весь ответ-карточка кликабельный, а не только текст.
- Темный интерфейс с почти черным фоном и кислотно-зеленым акцентом.
- Telegram WebApp API: `ready`, `expand`, цвета темы и `initData`.
- Python API: старт теста, проверка ответа и результат.
- Telegram `/start` показывает кнопку открытия Mini App.
- Ответы и активные сессии пока хранятся в памяти; после перезапуска активные тесты сбрасываются.

## Запуск

Установить Python-зависимости из `pyproject.toml`, затем:

```bash
python3 main.py
```

### Переменные окружения

```text
TELEGRAM_BOT_TOKEN=...
```

`TELEGRAM_BOT_TOKEN` нужно хранить в Replit Secrets. FastAPI слушает `0.0.0.0:8000`; `.replit` направляет публичный HTTP-порт на этот порт.

В Replit URL Mini App автоматически берётся из домена текущего приложения (`REPLIT_DOMAINS` для опубликованного приложения и `REPLIT_DEV_DOMAIN` в среде разработки), чтобы кнопка Telegram не использовала устаревший адрес. Вне Replit можно задать `MINI_APP_URL`.

## Источник вопросов

Файл:

```text
attached_assets/questions.docx
```

`quiz_data.py` читает таблицы DOCX напрямую. Если заменить DOCX новым файлом того же формата, база вопросов обновится при следующем запуске.

В исходном документе 311 записей. 3 записи имеют ответ, подготовленный в коде, потому что в исходном документе ответ отсутствует или отмечен вопросительным знаком. Это явно помечается в Mini App.

## Что осталось для публичного запуска

1. Загрузить этот проект в Replit/на сервер.
2. Убедиться, что сервис доступен по HTTPS.
3. Задать `TELEGRAM_BOT_TOKEN` и публичный `MINI_APP_URL`.
4. В BotFather настроить кнопку/ссылку Web App при необходимости.
5. После проверки можно добавить PostgreSQL для истории результатов и админку.
